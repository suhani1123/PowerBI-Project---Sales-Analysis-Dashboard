# Veloura Sales Analysis Dashboard – Power BI

An interactive **Power BI Sales Analysis Dashboard** built using a retail skincare sales dataset for **Veloura**, a skincare-focused business. The project focuses on transforming raw sales and customer data into meaningful business insights through data cleaning, DAX calculations, and interactive visualizations.

## 📊 Dashboard Features

The dashboard provides insights into:

* **Age Distribution** – Analysis of customers/orders across different age groups
* **Gender Distribution** – Breakdown of sales records by gender
* **Skin Type Distribution** – Analysis of customer skin types
* **New vs Repeat Customers** – Comparison of new and repeat customer records
* **Skin Concerns by Age Group** – Identification of skin concerns across different age segments
* **Best-Selling Products** – Products ranked based on quantity sold
* **Monthly Sales Trend** – Visualization of sales performance over time
* **Product Category-wise Sales** – Comparison of revenue generated by different categories
* **Payment Method Splits** – Distribution of transactions across payment methods

## 🛠️ Tools & Technologies

* **Microsoft Power BI**
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated columns and measures
* **Microsoft Excel** – Source dataset
* **Data Visualization & Business Intelligence**

## 📈 Key DAX Concepts Used

The project includes DAX calculations for:

* Total Sales
* Total Orders
* Total Quantity Sold
* Total Profit
* Average Order Value
* Profit Margin
* Age Group classification
* Age Group sorting
* Percentage-based analysis

## 🎯 Objective

The primary objective of this project is to demonstrate how raw customer and sales data can be transformed into an **interactive business intelligence dashboard** that helps identify customer demographics, product performance, sales trends, category performance, and purchasing patterns.

## 📁 Project File

The repository contains the Power BI `.pbix` project file and supporting dataset/resources used for creating the dashboard.
